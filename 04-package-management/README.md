# Package Management

## Objective

The objective of this lab was to practice package management on a Debian Linux server using the APT package manager.

## Tasks Performed

- Updated the APT package lists
- Checked for available package updates
- Searched for the Nginx package
- Installed Nginx
- Verified that Nginx was installed

## Commands Used

```bash
sudo apt update
sudo apt upgrade
apt search nginx
sudo apt install nginx
sudo nginx -v
