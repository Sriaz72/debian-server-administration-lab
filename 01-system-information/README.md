# System Information

## Objective

The objective of this lab was to identify and document basic system
information from a Debian Linux server.

## Environment

- Operating System: Debian GNU/Linux 13 (trixie)
- Virtualization: VMware
- Architecture: x86-64
- Hostname: Debian-2

## Commands Used

```bash
hostnamectl
cat /etc/os-release
uname -a
uptime
free -h
df -h
